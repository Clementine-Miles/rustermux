# Appearance sources

- The eight palette files are unmodified assets from [Termux:Styling](https://github.com/termux/termux-styling/tree/79338cb19f4b86cae4d2e81e6de60ba7f613bb9b/app/src/main/assets/colors). The repository is GPLv3-only. The two classic Gruvbox files retain their embedded author and [Gruvbox Generalized](https://github.com/morhetz/gruvbox-generalized/tree/150e9ca30fcd679400dc388c24930e5ec8c98a9f/xresources) attribution. The [Gruvbox project](https://github.com/morhetz/gruvbox/tree/ef8864bb42bf244f0295d1c5a403b27e3d139695#license) declares MIT/X11. The six Gruvbox Material files were added to Termux:Styling in [f5740fac09bea4cb2d2a10fba10e25e3015ac030](https://github.com/termux/termux-styling/commit/f5740fac09bea4cb2d2a10fba10e25e3015ac030). The [Gruvbox Material project](https://github.com/sainnhe/gruvbox-material/tree/11d779b26a9ab2b3db8c22c6ac9fb6e8ed4fea79) is MIT-licensed.
- `HackNerdFontMono-Regular.ttf` is extracted unchanged from the official [Nerd Fonts v3.5.1 Hack release](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1), source tag commit [`b894ea7803af6aade63d60a4381e006098ec9c4d`](https://github.com/ryanoasis/nerd-fonts/tree/b894ea7803af6aade63d60a4381e006098ec9c4d). `Hack.zip` was checked against the GitHub release artifact digest `fa24da7de7cefe7766614d27762570b20453c852fc1d5b657111666df9a5e449`. The TTF SHA-256 is `e5aeb58577a8acf2b42083e4a07ce48bd53116fdd868636403cadb5b547351be`. The release archive's license and glyph attribution are included.
- `JetBrains-Mono.ttf` is the Termux:Styling copy of [JetBrains Mono Regular 1.0.3](https://github.com/JetBrains/JetBrainsMono/releases/tag/v1.0.3), source tag commit [`a17943ec8a1a6f16c4bc55d34a297df91093bc29`](https://github.com/JetBrains/JetBrainsMono/tree/a17943ec8a1a6f16c4bc55d34a297df91093bc29). It matches the `JetBrainsMono-Regular.ttf` from the official archive byte for byte. The TTF SHA-256 is `3c5fb9d71ef1e2363ba27503f0b80907b34138c31a09c99cb5355171c62bc810`. This version is Apache-2.0-licensed.
